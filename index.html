Introduction to Temporal

Understanding the fundamentals of Temporal's architecture and why it's the perfect solution for building reliable distributed systems.

🏗️ What is Temporal?

Temporal is a microservice orchestration platform that simplifies the development of distributed applications. It provides durable execution for your code, ensuring that your business processes complete successfully even in the face of failures.

Core Concepts

  • Workflows: The orchestration logic that defines your business process
  • Activities: Individual units of work that perform the actual business operations
  • Workers: Processes that execute your workflows and activities
  • Task Queues: The mechanism for distributing work to workers
Simple Workflow Example
// A basic Temporal workflow
export async function orderWorkflow(order: OrderRequest): Promise<OrderResult> {
  // Step 1: Process payment
  const paymentResult = await processPayment(order.payment);
  
  // Step 2: Update inventory
  await updateInventory(order.items);
  
  // Step 3: Arrange shipping
  const shipmentId = await arrangeShipping(order.shipping);
  
  return {
    orderId: order.id,
    paymentResult,
    shipmentId,
    status: 'completed'
  };
}

Defining Workflows

Creating Temporal workflow definitions that orchestrate our one-click order process.

Order Workflow Implementation

src/temporal/workflows/order.ts
import { proxyActivities } from '@temporalio/workflow';
import type * as activities from '../activities/order';

const { processPayment, updateInventory, arrangeShipping, sendConfirmation } = 
  proxyActivities<typeof activities>({
    startToCloseTimeout: '1 minute',
  });

export async function orderWorkflow(orderData: OrderRequest): Promise<OrderResult> {
  try {
    // Step 1: Process payment
    const paymentResult = await processPayment(orderData.payment);
    
    // Step 2: Update inventory
    await updateInventory(orderData.items);
    
    // Step 3: Arrange shipping
    const shipmentId = await arrangeShipping(orderData.shipping);
    
    // Step 4: Send confirmation
    await sendConfirmation(orderData.customer, paymentResult, shipmentId);
    
    return {
      orderId: orderData.id,
      status: 'completed',
      paymentResult,
      shipmentId,
    };
  } catch (error) {
    // Compensation logic
    console.error('Order failed:', error);
    throw error;
  }
}

Implementing Activities

Building the business logic components that perform the actual work in our order system.

Payment Processing Activity

src/temporal/activities/order.ts
export async function processPayment(payment: PaymentInfo): Promise<PaymentResult> {
  console.log('Processing payment:', payment);
  
  // Simulate payment processing
  await new Promise(resolve => setTimeout(resolve, 2000));
  
  // Simulate random payment failures for demo
  if (Math.random() < 0.1) {
    throw new Error('Payment declined');
  }
  
  return {
    transactionId: `txn_${Date.now()}`,
    amount: payment.amount,
    status: 'completed',
    timestamp: new Date().toISOString(),
  };
}

export async function updateInventory(items: OrderItem[]): Promise<void> {
  console.log('Updating inventory:', items);
  
  // Simulate inventory update
  await new Promise(resolve => setTimeout(resolve, 1000));
  
  // Check inventory availability
  for (const item of items) {
    if (item.quantity > 10) {
      throw new Error(`Insufficient inventory for ${item.productId}`);
    }
  }
}

⚠️ Activity Best Practices

  • Activities should be idempotent (safe to retry)
  • Use appropriate timeouts for external service calls
  • Handle failures gracefully with proper error messages
  • Log important state changes for debugging

Building the Frontend

Creating the Next.js user interface with the famous one-click order button.

One-Click Order Component

src/app/page.tsx
'use client';

import { useState } from 'react';

export default function HomePage() {
  const [isOrdering, setIsOrdering] = useState(false);
  const [orderResult, setOrderResult] = useState(null);

  const handleOneClickOrder = async () => {
    setIsOrdering(true);
    
    try {
      const response = await fetch('/api/orders', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          items: [{ productId: 'laptop-pro', quantity: 1, price: 1999 }],
          customer: { email: 'customer@example.com' },
          payment: { method: 'credit_card', amount: 1999 },
          shipping: { address: '123 Main St, City, State' }
        })
      });
      
      const result = await response.json();
      setOrderResult(result);
    } catch (error) {
      console.error('Order failed:', error);
    } finally {
      setIsOrdering(false);
    }
  };

  return (
    <div className="container mx-auto p-8">
      <h1 className="text-4xl font-bold mb-8">One-Click Order Demo</h1>
      
      <div className="bg-white rounded-lg shadow-lg p-6">
        <h2 className="text-2xl font-semibold mb-4">MacBook Pro</h2>
        <p className="text-3xl font-bold text-green-600 mb-6">$1,999</p>
        
        <button
          onClick={handleOneClickOrder}
          disabled={isOrdering}
          className="bg-blue-600 hover:bg-blue-700 disabled:bg-gray-400 text-white font-bold py-3 px-8 rounded-lg text-lg transition-colors"
        >
          {isOrdering ? '⏳ Processing Order...' : '🚀 Order with One Click'}
        </button>
        
        {orderResult && (
          <div className="mt-6 p-4 bg-green-50 rounded-lg">
            <h3 className="font-semibold text-green-800">Order Successful! 🎉</h3>
            <p>Order ID: {orderResult.orderId}</p>
          </div>
        )}
      </div>
    </div>
  );
}

Saga Pattern for Compensation

Compensation Workflow
export async function orderWorkflowWithCompensation(orderData: OrderRequest): Promise<OrderResult> {
  const compensations: Array<() => Promise<void>> = [];
  
  try {
    // Step 1: Process payment
    const paymentResult = await processPayment(orderData.payment);
    compensations.push(() => refundPayment(paymentResult.transactionId));
    
    // Step 2: Update inventory
    await updateInventory(orderData.items);
    compensations.push(() => restoreInventory(orderData.items));
    
    // Step 3: Arrange shipping
    const shipmentId = await arrangeShipping(orderData.shipping);
    compensations.push(() => cancelShipping(shipmentId));
    
    return { orderId: orderData.id, status: 'completed' };
  } catch (error) {
    // Run compensations in reverse order
    for (const compensation of compensations.reverse()) {
      try {
        await compensation();
      } catch (compensationError) {
        console.error('Compensation failed:', compensationError);
      }
    }
    throw error;
  }
}

Production Worker Configuration
import { Worker, NativeConnection } from '@temporalio/worker';

async function createProductionWorker() {
  const connection = await NativeConnection.connect({
    address: process.env.TEMPORAL_ADDRESS!,
    tls: {
      clientCertPair: {
        crt: await fs.readFile(process.env.TEMPORAL_CERT_PATH!),
        key: await fs.readFile(process.env.TEMPORAL_KEY_PATH!),
      },
    },
  });

  const worker = await Worker.create({
    connection,
    namespace: process.env.TEMPORAL_NAMESPACE!,
    taskQueue: 'production-orders',
    workflowsPath: require.resolve('./workflows'),
    activitiesPath: require.resolve('./activities'),
    maxConcurrentActivityTaskExecutions: 100,
  });

  return worker;
}
